## 固定上游与本地配置

本轮核对[官方发布 v1.0.1](https://github.com/a2aproject/A2A/releases/tag/v1.0.1)，固定提交 `3303592588e388e62e0f69f701af531d2f4e3991`；依据该提交的[规范](https://github.com/a2aproject/A2A/blob/3303592588e388e62e0f69f701af531d2f4e3991/docs/specification.md)和[规范 proto](https://github.com/a2aproject/A2A/blob/3303592588e388e62e0f69f701af531d2f4e3991/specification/a2a.proto)。发布标签为1.0.1，HTTP `A2A-Version` 和卡片接口版本固定1.0，两者不能混写。上游字节／许可清单见 `tests/fixtures/a2a/v1/upstream-lock.json`，下载原文在忽略目录 `.agentgit/evidence/S12-D-upstream-v1/`。不跟随 main/latest，不新增 SDK、框架或依赖。

首批为已登记本机独立进程的 HTTP+JSON 接口，只接受明确端口的 `http://127.0.0.1:{port}`。支持发现卡片、发送用户消息、查询确切任务、取消确切任务，以及内嵌文本／结构化消息和产物。卡片发现地址固定 `/.well-known/agent-card.json`，操作为 `/message:send`、`/tasks/{id}` 和 `/tasks/{id}:cancel`；发送返回的 task 包装与查询直接返回 Task 分别解析，采用 ProtoJSON 字段名及枚举值。请求使用 `application/a2a+json`，有界解析响应和错误，不将不可信错误文本直接写入历史。

仅使用本地预置的 Bearer 身份，不实现 OAuth 登录、动态凭据获取、租户路由、卡片签名、流式／推送、任意扩展、外部文件 URL、公网或多租户部署。卡片内接口必须精确匹配登记端点／协议；不能用远端卡片扩大权限或改写连接地址。拒绝代理、DNS 重定向、HTTP重定向、私网地址、跨端口、URL凭据和额外网络下载。读取卡片的公开信息不能代替任务身份认证。

## 项目效果与耐久边界

首个业务范围为固定的远端资料整理任务：仅传显式公开输入，返回可审计文本／结构化产物；不自动发送四角色私有备注、宿主文件或其他项目历史，不开放远端执行工具。此范围是 AgentGit 的适配配置，不声称实现完整 A2A Server 或任意 Agent 互操作。

复用原 Run／Job／History／CAS、租约与 fencing、调用网关、预算、精确审批和 Recorded 来源契约。发消息会创建／更新远端任务，取消会改变远端状态，两者按本地外部写策略处理；不能因为远端声称只读而降为 READ_ONLY。发现／查询为只读。发送前耐久保存确切请求意图、消息 ID、端点和非秘密身份绑定，结果耐久后恢复不能再次实际发送；未知结果保留待核对，不因网络错误、失租或重启自动重发 POST。确认过的任务 ID 只能用于同端点／身份／项目绑定的查询和取消，不能凭用户提供的任意远端 ID 越权操作。

规范允许 Send Message 实现幂等，并未保证所有服务均幂等。本地可信 fixture 额外承诺同身份／messageId／完整内容去重，变更内容拒绝；这是本地支持配置的要求。即使对端承诺幂等，客户端仍不以该承诺代替本地意图和未知结果处理，也不推断新任务 ID。取消幂等不等于可以在缺少确切任务 ID 时猜测取消成功。暂停只停止本地推进；取消已接受与远端已取消分开记录。过期、404、拒绝、需要输入／认证、超时及未知分别可追查，不能误记完成或自动发起新任务。

凭据仅在运行时注入，不进入配置快照、CAS、日志或错误正文；测试逐项检查回显、其他身份和其他项目。期限和物理调用预算跨恢复累计，不能靠轮询或续跑重置；轮询次数有界。断连前／后、结果／Commit耐久前后及任务取消交错均需真实进程测试。

## fixture、Recorded 与交付顺序

先固定 `tests/fixtures/a2a/v1/` 的卡片模板、任务输入／产物、场景清单和上游摘要，再实现仅供测试的独立进程服务；测试服务不得导入产品代码，用独立日志观察实际请求、接受消息和任务数量，避免产品与 fixture 共用解析器掩盖错误。fixture 自检仅证明测试设施行为，不计作产品适配或 T04 通过。

之后依次实现有界契约／传输、Live耐久 Run／控制／真实进程恢复、成功轨迹 Recorded、API／CLI／桌面与最终包。Recorded 固定成功来源和逻辑投影，消费录制的协议响应重算状态与产物，保留原远端物理 ID 的审计对应；本次物理网络／任务创建为0，禁止创建真实客户端。缺录制、错误端点／身份／程序签名、被篡改消息／产物必须失败，无 Live 回退。取消／未知轨迹是否支持 Recorded 必须单独声明，不能混入成功范围。

T04覆盖未授权、跨身份、重复、变更重复、断连、任务过期和取消；T05覆盖零网络／状态与产物 hash／缺录制；T07覆盖地址、重定向、响应上限和凭据。接入后执行T06相关核心、恢复、HEAD竞争、跨项目、双父合并、终端／Python Recorded和桌面兼容。最终提供独立进程演示、`acceptance/S12-D.md`、四适配新桌面包和D3汇总；任何部分未完成均保留未完成，不能据 fixture 或单批后端测试宣布 D／S12 退出。
