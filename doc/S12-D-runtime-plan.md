# S12-D 耐久任务实施细则

2026-10-31，接续 `d81d90b` 的客户端／调用网关。根设计／实施方案及锁的摘要未变；本细则继续原工程授权，不替代正式前置，不合并main。

## 固定程序与现有内核

新 `a2a_run` 仅复用原Run／Job／History／CAS、租约／fencing、版本锁及精确审批，不新增业务表或依赖。迁移只扩展Job类型约束，只在自有测试Schema运行；降级遇到该类型数据必须拒绝。源码／锁进入不可变Job载荷，Worker接管时严格核对，不改旧研究release守卫。

程序固定卡片／端点／非秘密主体、1–4条有序公开文本消息、轮询次数／间隔以及原 `BudgetLimits`。消息ID不重复，不允许调用者传入远端task/context或回执引用。只有本Run已登记、已确认、签名匹配的调用结果才可派生任务引用，后续查询／取消／追加消息均复查该来源。后续消息只在远端要求输入且确有预声明消息时选取，每次发送仍单独审批；没有预声明后续消息时保留等待输入，不能编造回复。

逻辑调用先耐久预留，再经原网关保存意图／结果；用量跨等待审批、暂停、排队和接管累计，不能因恢复重置。轮询借原Job的 `available_at` 延后领取，发布检查点与释放租约同事务；不持有数据库事务进行网络请求，也不让Worker阻塞睡眠。保留原deadline及轮询上限，为取消预算预留空间，实际不足时明确停止而非扩大额度。

读取完整耐久结果优先于控制／新请求；进程在结果后中断时消费原结果，在已保存意图但无完整回执时保留未知、零重发。协议错误、预算耗尽、过期任务、远端失败／拒绝、要求输入／认证和已完成分别保存。网络客户端只在确实需要新调用且控制允许后创建，排队暂停／取消和已知回执接管不应建立连接。

## 控制与产物

暂停只停止本地推进。取消未发起的任务可本地完成；有确切非终态远端任务时，生成独立精确取消审批，确认回执为CANCELED才记远端已取消。拒绝、未确认或未知取消不能伪装为远端停止；对已知终态不盲发取消。先前尚未执行的待批准动作在暂停／取消改变检查点时失效，已消费或未知意图不能撤销后重发。

远端原始产物名不作为宿主路径；将已校验回执和产物发布到固定 `a2a/` 前缀／本地编号路径，以原CAS、文件数和总字节上限核对。事件保存每次预留、观察、轮询调度、等待、控制和未知的因果顺序。提交必须原子绑定状态、产物、分支版本、Job租约和Run状态。
