# S6 四页视觉参考

本目录保存按现有 DESIGN / PRODUCT / 四页字段清单生成的完整窗口参考，不是可执行界面，也不是真实业务证据。用户已授权按项目方案自动推进，因此采用同一既定方向实现；不宣称这些图片经过人工逐张批准。

| 图片 | 内容与主要约束 |
|---|---|
| runs.png | 项目运行表格、新建目标/预算、三/五工具权限；奶油底色、衬线标题、平面暖珊瑚操作 |
| timeline.png | 检查点图与事件、同页执行详情，命令/代码、日志、结果与版本文件 |
| branch.png | Recorded / Live 的互斥字段、来源、安全起止点、独立预算与权限说明 |
| diff.png | Commit 选择、路径列表、前后值、二进制摘要与客观差异证据 |

生成方式：内置 ImageGen；以 Runs 图作为其余三页共同的应用外壳参考，1536×1024 原始 PNG，未进行 Python 图片编辑。素材用于设计核对，不作为整张网页背景或静态生产数据。英文/中文示例文字、日期、版本、计量、摘要均为概念占位值。

实现修正以项目规范和真实数据为准：

- 图片示例中的蓝色状态点改用 DESIGN 已有 teal，并始终保留文字状态；按钮使用已记录 AA 对比度的 accessible 变体。
- 实际主内容最大宽度 1200px；正文使用本地 Inter，标题使用 DESIGN 允许的 EB Garamond 及系统中文衬线回退，代码使用本地 JetBrains Mono。
- 修正图片中的 2024 日期、伪摘要、JSON Pointer 占位等；界面只展示 API 原始事实，没有预置成功行或 AI 因果置信度。
- 执行证据与所选历史状态分别标明，Recorded 不冒充新执行；导出按产物 ID 与原生对话框进行。

四页真实 Electron 初版截图与图片核对后，保留暖底色、水平导航、标题/正文字体分工、表格、图/详情区与路径/前后值布局。实际长度按数据滚动，不把概念图的固定高度当作裁切要求。
