# S5 Live 独立重执行批次

本记录只覆盖 Live 子批次；完整 S5 验收现已汇总于 [S5.md](S5.md)。后续复合 Recorded 结果见 [S5-compound.md](S5-compound.md)，可信核对及接管封存见对应专项；S6、必选 S11 和 S12-A/B/C/D 的交付范围保持不变。

## 实现

- API 与 CLI 共用严格分模式请求。Recorded 拒绝干预；Live 拒绝 until，支持完整配置/计划、版本化文件增改删和类型化执行参数。
- 新配置、Task、Job、Run、分支和初始输入归属原子提交；相同 actor/route/key 返回原响应。来源分支与检查点不变，提交不创建可执行工作区。
- 初始状态保留历史完成节点、工作记忆及累计用量；清除未完成 attempt、待结算旧轨迹、停止证书和循环/终态标记。已完成计划节点不能改写。
- 冻结预算基线并写入新环境；新增步骤、模型/工具调用、Token 和重规划按差额计量，保留累计 occurrence 编号。自身恢复沿用基线和持久截止时间。
- 首次保存 live.initialized，之后正常执行和记录。来源审批及调用结果不进入新 Job 的恢复复用链；新实际容器重新绑定输入清单和策略。
- 状态报告区分累计逻辑用量、新增预算消耗和自身物理尝试，排除恢复复用；未知结果独立展示。新 Live 初始化后的同环境范围可再执行 Recorded，实际调用为零。
- 输入文件解析前限制大小，来源文件累计读取有界；纯产物工作区使用 64 MiB 上限，容器输入保留 32 MiB 上限。96/240 字符路径的初始归属、实际物化、Commit 和 Recorded 往返通过；短引用角色保持兼容，长角色使用路径摘要，不修改冻结镜像代码和既有迁移。

## 验证

新增专项包括输入约束、计划与同名产物 A/B 隔离、独立小预算、初始化事务崩溃/提交后恢复、结果落库后恢复、再次 Recorded、HTTP/CLI 共用幂等以及重新审批。

真实 Docker 的 Shell/Python A/B 用例均通过：各分支写 results/same.txt 的不同字节，输入清单不同，所有 container_id 唯一且清理确认；不继承来源或另一分支的 /tmp 文件，原分支与来源快照不变。独立 fake 写服务验证相同参数仍新建 pending 审批，审批前没有新请求或物理工具调用。

本批先运行全量两组：单元/集成 **413 通过**、701.86 秒，真实容器/执行 **108 通过**、882.93 秒，分别记录在 `.agentgit/evidence/S5-live-core.xml`、`S5-live-execution.xml`。这是输入边界和长路径最终修正前的完整基线。

随后输入边界修正的单元及 Live/Recorded 核心专项 **245 通过**、309.32 秒（`S5-live-final-core.xml`）。长路径调整曾误触冻结镜像共用模块，11 项策略前提测试明确失败（`S5-live-policy-guard-failure.xml`）；辅助函数移到存储层后，冻结源码和固定镜像重新核验通过，相关 26 项先行回归通过。

最终扩大回归 **263 通过**、252.46 秒（`S5-live-final-paths.xml`），覆盖全量单元、历史内核/版本、迁移往返、Live、重新审批和耐久 Recorded；最终真实 Shell/Python A/B **2 通过**、66.30 秒（`S5-live-final-execution.xml`）。全仓现在收集 **526 项**；最终修正后补跑以上相关范围，未声称再次完整运行全部 526 项。Ruff 格式检查为 134 个文件，mypy 为 76 个源码文件；无遗留受管执行容器。

公开 CLI 的独立 A/B 冒烟记录在 `.agentgit/evidence/S5-live-cli-smoke.json`：各新增一次模型调用和一次终端调用，`results/live-cli.txt` 内容及摘要不同，来源主分支不变。Ruff、mypy、sdist/wheel 构建及 `doctor --sandbox` 均通过；不推送、不声称远程 CI 或完整 S5 验收已完成。
