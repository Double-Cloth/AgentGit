# S10 Repair Lab 可见页面与只读流程

2026-10-27，分支 `codex/s10-repair`。本增量接通第五页“修复实验室”、时间线交接、只读流程发现和精确审阅；沿用既有 React/Electron、DESIGN.md、字体和颜色。未生成新安装包，没有迁移业务库或调用付费模型。完整桌面设施联调、30 例/四基线、D2、S11/S12 及用户暂缓项目仍需继续，不宣告 S10 完整退出。

## 用户操作

页面核对失败终态与模型决策前起点，可显式冻结 screen 验收器；原子准备请求包含有限事件、四个不同回归来源、完整预算及可选 Hybrid 条件。必须勾选执行授权；外部模型必须提供明确预算，不能标为随机 Mock。默认空间、阶段次数和后端权限不扩大。

搜索列表及 UUID 查询通过只读 workflow 取得既有 suite/study/proposal，窗口重开不通过 POST 寻找记录。冻结失败断言、候选和完整输入可见；筛选、原子/字段缩减、候选锁、确认/回归和最终建议分别展示。试验组件保留失败/未知收据、投影和执行入口，缺失计量不显示为零。显示实际阶段次数、物理用量、停止原因、Wilson 区间及适用条件，筛选通过和固定条件下验证通过使用不同状态文字。

缩减、锁后开池和生成精确建议均需显式操作。建议展示来源/建议配置原文、确切补丁、任务/环境和完整报告；审阅票据绑定建议摘要、来源配置、锁、验证摘要和项目配置计数器。票据失效禁用决定；提交时版本竞争返回冲突后清除旧票据，必须显式重新核对。批准仅创建配置版本，保存实验不执行，界面不自动创建 Task、Run 或 Replay。

工具观测替换始终标 test_only 和仅实验范围，正式配置批准禁用并说明原因；确认/回归未达标不能批准或作为合格实验保存，仍可获取票据后拒绝。缺少或非法摘要、版本、来源绑定不能成为可用采纳动作。

每次修改冻结请求和原键，防双击；未知响应只允许原键确认，明确拒绝才释放请求。断连禁用操作，保留已确认报告；刷新失败显示旧结果及错误，不能把旧值当作最新值或重判为零。切页/重开不自动重发修改动作。

## 分开的证据范围

真实 PostgreSQL 集成用例先完成实际筛选、缩减和六加四，再创建精确建议；验证 workflow 在建立建议前/后正确发现既有身份，并在禁止 CAS 写入和修改服务调用时重复 GET。不同项目查询被拒绝。此项与 700 单元共 701 项通过，不意味着 Electron 已连接这套真实设施完成同一流程。

真实 Windows Electron 使用明确 HTTP fixture 操作可见页面，覆盖完整准备/缩减/开池/建议/票据/批准路径；丢失提交响应后原键/参数相同，双击只发一次；版本刷新导致禁用，以及实际 HTTP 409 后重新取票据；观测补丁禁用正式批准但可保存实验；报告 503 保留已确认内容、API 断连禁用并保留报告、恢复与重开没有额外 POST。没有调用 tasks/runs/replays 创建接口。单独 preload 桥接与旧四页/连接边界也通过。原生框架与窗口是真实的，服务数据仍是 fixture，不能替代真实 API/Worker/CAS 一体联调。

34 项桌面单元覆盖请求来源、事件/预算边界、票据绑定、版本、观测范围和失败拒绝；最终页面专项 2 项、旧界面专项 2 项通过。typecheck/build、Ruff/格式和 mypy 通过。既有供应商与独立 Windows/DPI/安装等范围未执行。

## 视觉与探索修正

在 1440×1000 与 360×1000 请求视口检查真实 Electron 截图和横向溢出。窄窗口导航原先挤字，改为导航容器内横向滚动且保持完整词组；配置对照按既有断点堆叠，代码在自身容器滚动，页面不整体溢出。状态文字、测试范围和不可操作原因可见；外部 HTML 字符串按文本显示，没有执行或生成图片元素。沿用字体、颜色和焦点体系；检测器发现的既有 Inter/旧定位边框不触发重新设计。

首次夹具使用非十六进制摘要，被主进程验证拒绝；修正为合法摘要，并补上界面采纳门禁的完整性检查，没有放宽主进程。断连测试曾对 fieldset 使用不适用的 disabled 断言，实际 disabled 属性已存在；改为断言其中实际按钮的有效禁用状态。失败 XML/trace 保留，不与最终通过累计。

旧四页复验最初调用默认报告路径，默认 S6 边界 XML 被本次结果覆盖；当前结果已单独归档，不作为原 S6 原始报告。旧配置现增加与其他专项一致的证据前缀，以后新复验不会覆盖通用路径。各历史结论不能据此次报告替换；最终分发仍需独立复验。
