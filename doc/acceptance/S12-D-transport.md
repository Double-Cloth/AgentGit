## 已实现行为

`core/a2a_wire.py` 固定消息、任务、回执引用和结果：只发送显式公开文本，支持返回文本与 AGJSON 结构化 Part；保留八种明确任务状态，校验消息／产物数量、标识唯一性及嵌套任务／上下文。拒绝 URL／raw／filename Part、未知字段、任务路径注入、浮点数据、任意推送／延迟返回配置和跨上下文回执。原始产物 name 仅为数据，不按远端名称写入宿主文件。

`adapters/a2a_http.py` 只连接登记数字回环地址和端口，固定三个任务路径及发现地址；忽略宿主代理，不跟随重定向，不自动重试。支持有界 Content-Length、close-delimited 和 chunked；拒绝长度歧义、CL+TE、非声明媒体／压缩、截断及超限。总期限通过保留实际响应 socket 中断读取；连接前、连接后检查权限／租约守卫，守卫返回后再次检查期限，过期时不尝试发送。

`adapters/a2a.py` 经原 `CallGateway` 绑定操作、完整请求和卡片／主体签名。发现不发送凭据；其他操作只从运行时环境取得 Bearer。正文／引用／卡片在进入网关前检查秘密，避免网关先写出的未登记 CAS 文件泄露；响应秘密及不可信错误原文不进入历史。固定结构的认证／权限／缺失任务／版本等拒绝映射为稳定错误；已经可能发出的发送／取消没有可信回执时为 `OUTCOME_UNKNOWN`，不将 HTTP 500、非法401正文或错误结果当作可重发失败。

回执引用绑定端点／主体／卡片和确切 task/context，以及成功结果摘要；它只是内容引用，不能代替应用层的本人／项目／Run／Commit 归属核对。当前尚无公开任务入口，后续 Run 服务必须核对其同项目、已确认调用来源后才能执行后续查询／取消／追加消息。
