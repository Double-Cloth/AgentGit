T08 的负向条件通过阻止测试进程构造/访问真实执行客户端实现；没有关闭同时承载测试 PostgreSQL 的宿主 Docker Desktop。真实正向来源和容器隔离已单独实际执行，不能将禁止访问等同于新增的宿主引擎停机测试。

fake 写工具仅由后端测试 fixture 提供。测试中的纯 Registry 使用当前可信 fixture 计算的效果分类和签名，绝不根据录制环境的自述放宽兼容性；默认生产 Registry 仍拒绝该自定义绑定。此证据不宣称公开 API 支持任意未知 Adapter。

[版本与初始重算](S5-progress.md)、[可信清理/丢弃](S5-progress.md#停止丢弃来源重算)、[直接模型未知与结算](S5-settlement.md)、[接管封存未知](S5-sealed-unknown.md) 分别记录原始来源边界。完整结果先结算再处理控制；未知结果没有完整回执时不重发，固定容器可以在可信清理和预算结算后按既有策略创建新 attempt。任意未知容器输出没有回执时不能导入成功产物。
