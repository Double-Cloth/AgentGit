# S10 新数据五方法驱动原型与故障规格 v2

2026-10-27，分支 `codex/s10-repair`。新驱动已在 R07 开发联合例完成五种方法，保留正常、失败及无解结果，原始 CAS 独立审计通过。此运行是工程原型，不计入冻结后的 30 例、12 例开发目标或 D2；R21–R30 仍未运行。

## 原型的实际范围

一例共用同一个失败来源、四个预注册独立回归来源和两种固定只读参考环境。参考环境对所有类别相同，不以参考 Run 成败筛选；只按响应字节与原观测相等排除无变化项。局部方法在自己的合法局部起点生成候选；其余方法使用根起点，主方法保留完整候选降级。所有方法继续经过原模板服务、S7 干预、搜索/缩减/确认控制器及普通 Worker，预算 30 次、单 trial 上限及保护的六加四保持。

R07 五方法结果为：repair、first_exception_local、unordered_enumeration、combination_without_reduction 均为 verified_under_fixture，各六次确认、四项回归全部通过；global_prompt_once 在其选定空间内 no_solution_in_space。后者仅有固定证据 Prompt，不能补齐缺失的计划交付。无排序与主方法的原子顺序、实际调用和字节相同，不宣称排名优势。不缩减方法没有删除/字段试验，最小性仍未证明。

最终 86 个 Job/Run 共 682 次实际模型、552 次实际工具、7,324,355 Mock UTF-8 字节；包括七个准备 Run，各方法试验成本另列。归档 3,972 个对象、8,921,602 原字节。24 个确认和 16 个回归均绑定不同实际 Run，固定来源轨迹未变，无配置审批或采纳。该单例具有开发可见性，不是无偏效果研究，也不能推广局部或主方法优势。

早期单方法原型先暴露 Recorded 的签名不兼容：生产重放要求配置声明的固定 Mock 接口签名。故障模型现沿用该接口，故障条件及适配器源码另形成 fixture_ref，在研究归档/完整 release 中绑定；生产兼容性检查没有改动。随后单方法 v2 实际六加四通过，五方法 v3 再统一观测候选来源；旧结果均保留，不重复累加。

## 证据编码与独立核算

整例归档使用 `objects.bin` 加类型/长度/偏移索引，限定 60,000 对象、256 MiB 原字节和每表 100,000 行。文件只创建一次，不裁掉失败记录。读取同时验证容器摘要、连续边界、仓库归属及每个 CAS 类型域摘要；六项拒绝损坏测试覆盖伪造容器摘要后对象仍不匹配等边界。归档上限不改变产品或试验预算。

`repair_benchmark_verify.py` 重算每条模型响应、冻结硬验收、登记时间、各阶段实际调用/字节及六加四。Hybrid 的 recorded/synthetic 观测经冻结 policy 和 provenance 验证，不能只看 external_calls.origin_call_id 就算成新工具调用；原型中有 42 条此类虚拟观测，实际成本已经排除。来源、逻辑继承与本次实际成本分别保留。

最终五方法证据位于忽略目录 `.agentgit/evidence/S10-dataset-prototype-v3/`，含 R07 的二进制原始证据及执行时的确切源码；对应 `S10-dataset-prototype-v3.xml`、`S10-dataset-prototype-audit-v3.json`。源码快照用于解释该原型，后续规格修改不覆盖旧字节。

## 冻结前修正家族重叠

原输入资产 v1 的 13 个家族只是未验证提案。机制复核发现开发路径指令与保留指令攻击共用同一触发模板，不能仅按攻击目标改名跨 split。新 `faults-v2.json` 保留 30 个 ID、原公开输入、五类配额、20/10 和十二个开发目标分母，归并为 11 个机制家族：所有六个外部指令例只属于同一个保留家族；R19/R20 改为独立导出路径缺陷，不再依赖外部资料指令。

另一项保留引用缺陷改为读取过的真实引文跨事实行关联错误，与开发例编造不存在的引文区分；其结果不随搜索排名改变，而开发排名缺陷可被排名观测改变。外部提纲引发的计划遗漏与机械计划遗漏通过去除外部指令的反事实分开核对。这些仍是 agent_proposed/unverified 标签，因果隔离契约不冒充人工 gold 或真实模型泛化。

当前 73 项契约通过；另只对改动的两个开发路径机制执行四个真实源/正常对照 Run：48 模型、36 工具、491,594 Mock 字节，两个源均两次越界写 validation 拒绝、零产物并以 loop_detected 停止，两个正常对照通过。原始响应/硬验收独立核对，证据在 `S10-path-v2-construction-v1/`、对应 XML 和 `S10-path-v2-audit-v1.json`。这些新构造不算修复成绩；五方法原型使用此前冻结模型源码，其 R07 机制未改，不将不同版本结果混成正式评估。
