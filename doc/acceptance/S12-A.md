## 实现及边界

- `core/mcp.py` 固定本地身份、唯一数字回环端点、协议 `2026-07-28`、超时/响应预算和不可变完整工具定义。Schema、端点、效果分类进入调用签名；嵌套定义通过 canonical 文本固定。远端只读/幂等提示不能修改本地策略，外部写入保持精确审批。
- `core/mcp_schema.py` 验证已声明的闭合子集，拒绝 `$ref`、浮点/number、组合/正则、自定义头和其余未实现关键字；输入/声明输出均检查，不忽略未支持约束，不构造解析引用的客户端。
- `adapters/mcp_http.py` 单次直连固定回环、拒绝代理/重定向/SSE/压缩，限制请求和完整响应，按总期限关闭底层 socket。针对 `Connection: close` 把 socket 从连接对象转交给响应体的情况，保留底层句柄并显式关闭响应；专门单元验证该边界。
- `adapters/mcp.py` 有界分页发现和固定定义缓存、调用前重核、标准化结果/错误。网关记录意图、请求/结果和事件，原响应包含本地身份、工具名、Schema/参数摘要、实际延迟和效果；response_ref 使用既有 CallTrace，不额外拼接轨迹。已发送写入未取得可信成功结果保持未知，无内部重试或自动审批。
- 凭据只从客户端进程环境注入 HTTP 头。业务参数中的凭据字段/确切运行时值在进入网关前拒绝；远端回显确切值也拒绝，固定错误不反射远端正文。测试仅使用公开的虚构 sentinel，不使用真实密钥。Recorded 只持绑定和原始录制，不构造 Live 客户端、重新发现或补发，缺失录制明确失败。

没有新增依赖或迁移，Schema head 保持 `0026_merge_runs`；没有修改既有五工具授权、容器边界、研究 Runtime 或桌面分发包。尚未登记 stdio 可执行程序，产品配置拒绝 command 等未知字段，不存在远端启动宿主命令的入口。首批只支持明确 HTTP JSON 子集，不宣称完整 MCP 实现或任意 JSON Schema 支持。关闭传输不证明远端副作用撤销，也不提供已确认的远端取消。
