## 范围与实现

新增有限研究 Runtime、Mock LLM、固定语料、三个基础工具和独立报告验收器；配置不可变且按项目版本化，Task/Run 和计划投影使用同项目复合外键。Run 状态、计划/节点投影与 state/Artifact Commit 在同一 S2 事务中提交。终态重试创建新 Run、关联 origin Run 并分配新的 Task 计划版本，保留旧计划记录。

规划输出、工具决策和终态响应分别通过严格 Schema；每次接受决策与完成观察均持久提交。DAG 验证缺节点、重复节点及环，派发时再次核对当前前置条件和工具类型。重规划最多两次，不能改写已完成节点的定义。完整 state 包含短期调用引用、结构化来源记忆、计划、待执行动作和预算。

调用先保存意图，再在数据库事务之外执行 Adapter，随后耐久保存原始响应/错误。相同 occurrence 的已保存结果复用，参数/签名/效果分类/checkpoint/响应限制不符则拒绝；已有意图但没有结果时停止为 outcome_unknown，保留预算预留，不盲目重发。此为 S4 恢复的基础，不等同于已交付 Worker 恢复或 S5 Recorded Replay。

固定语料为 Aster/Birch/Cedar 三个虚构框架、各两份资料；评估时间 `2026-10-20T00:00:00Z`。权威包内 JSON SHA-256：`989095a07aea8f99fdc0e79ce3e8f8fb3ab6591b60382ed2bf534ca5027aad6a`。正文有 hash、引用原文、采集日期与有效期，外部文本标为 untrusted_fixture；URL 不访问网络。

`artifact_write` 仅写独立 Run 工作区，检查路径、父目录链接/联接、大小/数量与文件类型；通过独立临时文件替换避免截断宿主硬链接目标。完成的文件与状态一起进入不可变 CAS，历史读取不依赖当前工作区。

## 限制与下一阶段

- 只支持明确的三框架合成研究任务与受约束报告格式，不是通用自主 Agent。当前示例同步运行，并从含 uv.lock 的项目源码环境构造环境清单；包内语料已验证可分发，独立安装后的完整 SDK 执行入口不在本阶段范围。
- Model `tokens` 标记为 mock_utf8_bytes，按请求/响应 UTF-8 字节数做合成计量，并非供应商 Token；Mock 费用为零，不推断真实模型成本或价格。S7–S10 的搜索/复测预算尚未接入。
- 墙钟在调用前后和步骤边界核验；当前 Adapter 是受控本地实现，不声称可强制抢占任意阻塞函数。独立截止时间守护、资源限制与进程清理必须在 S4 真容器验收。
- 双 Run 测试阻断 Python socket 连接并断言连接调用计数零；本机 PostgreSQL 回环连接仍为基础设施依赖。这不能替代 S4 的容器断网测试。
- 只有 corpus_search/source_read/artifact_write；terminal_exec/code_exec、Job/租约/fencing、暂停/取消/恢复、审批及完整 API/CLI 均待 S4。S5 Replay、S6 四页和 D1 也尚未完成。
- 保留已记录的 Starlette/httpx 弃用提示，没有隐藏警告或新增依赖。schema_s3.py 与已归档迁移应保持冻结，后续通过新迁移扩展。

下一步按 S4 顺序实现持久化调度和恢复契约，再完成终端/Python 的真实执行、隔离、限额、清理及副作用验收；S12 四项仍为完整交付必选项。
