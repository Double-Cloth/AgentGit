# S9 有限模板、枚举与预算基础

日期：2026-10-24。分支 `codex/s9-repair` 从 `8d94f29` 开始。依据设计文档 5B.4、实施方案 S9/6.2；本记录仅覆盖[方案](../S9-repair-plan.md)的第一增量，不替代 S9 的持久搜索验收。S6/D1 原生/独立环境和 S8 人工审阅按用户指示暂缓，主要定位指标仍未达标，搜索工程显式记录完整候选降级。

## 实现范围

- `core/repair.py`：严格冻结 Patch、Binding、Space、phase/repeat trial 身份、多维预算及消费契约。
- `repair/templates.py`：两个固定 Prompt 约束、缺失产物 Plan 节点和仅测试的录制观测候选；模型模板先核对完整快照/配置摘要并复用 Live 安全检查。不会修改已完成节点、扩大工具权限、清除 pending tool 或生成任意路径写入。
- `repair/space.py`：最多八项原子、深度二、先单点后有序双点，同字段冲突拒绝；提案键保留顺序并绑定环境/验收器/策略；独立重复 trial 绑定搜索和重复序号；输入和排除摘要有上限。
- `repair/budget.py`：阶段/总次数、并发、调用/Token/费用/墙钟准入；screen/reduce 保护完整确认及回归资源，未知试验保留完整上限，实际量明确才允许释放差额。

本增量无迁移、后台调度、API/CLI、桌面修改或包发布；不自动迁移业务库，不改执行核心。新代码和测试均使用既有依赖。
