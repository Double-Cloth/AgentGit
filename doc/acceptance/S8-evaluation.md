## 连接池故障与修复

单连接、禁止溢出的真实 PostgreSQL 测试复现 QueuePool 超时：修改事务持有唯一连接，编译行为图又申请读取连接。现改为先查已提交幂等结果，再在事务外只读编译，最后用原管理事务的幂等锁再次核对并原子发布。并发可以重复只读编译，不能重复创建报告；已完成同键重试直接返回缓存，不重新编译。

单连接创建、两连接六路同键、同键异参竞争、发布中断回滚/同键重试通过。共享幂等摘要和缓存核对提为同一实现，既有管理入口接受回归；没有扩大连接池、引入后台任务或绕过项目边界。CAS 先写而 SQL 回滚时可能留下不可访问的未索引对象，沿用既有内容存储/GC 语义；不会留下可访问报告或幂等成功记录。

旧 [v1 规则快照](S8-static-rules-v1.json)保留。新增[存储修正快照](S8-static-rules-v1-storage-2.json)，排序/行为模块字节不变，报告的读取、头核验、断言提取、编译及列表方法 AST 与 `a23d6c8` 一致；仅编译/持久化协调变更。排序域摘要保持原值。
