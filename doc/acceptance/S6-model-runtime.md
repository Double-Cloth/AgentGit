# S6 模型运行时与回放接线

日期：2026-10-23。继 [HTTPS/协议基础层](S6-model-foundation.md) 后完成后端接线；仍不等同于供应商质量、账户访问或 S6 整体通过。显式配置、字段与限制见[模型说明](../MODEL_ADAPTER.md)。

## 实现

- `AgentConfig` 增加固定 OpenAI 模型与可选供应商选项；真实模式必须同时声明正整数 USD 预算，缺项明确拒绝。`BudgetLimits.within` 对可空费用上限定义收紧语义，防止 Run/Live 通过省略上限来扩大授权；Mock 默认字段、JSON 和签名保持原样，新增 None 字段不进入原 JSON。
- Worker 默认按冻结配置选模型，保留原测试工厂注入；Session 的环境清单、调用 provider、供应商签名及外部只读策略一起绑定。构造、配置读取、签名计算和 Recorded 均不读取供应商密钥。
- `ModelCallBudget` 在实际调用前随意图耐久保存；Gateway 的缓存/来源复用及 Recorded 均核对它。`runtime/model_budget.py` 共用纯预留与结算规则，取代真实模型路径中的 Mock 字节计量。无新数据库迁移或外部依赖；为明确 `exclude_if` 序列化能力要求，将 Pydantic 声明下限收紧到已锁定并验证的 2.14.1，41 个外部包条目逐值未变，固定沙箱内核及镜像不变。
- `ModelTotals` 将实测、保守估计、未生成、缺明细和未核价费用分开。可验证回复先结算，再执行既有决策/计划/工具/独立报告验证；受控停止不会被旧的 Schema 重规划逻辑误重试。明确可重试响应才沿现有上限重规划，退避仅发生在真正 invoke 中，Recorded 不等待网络。
- 生成后未知维持 Token 与费用预留；崩溃接管由冻结意图重算；可信回执由原 `_settle` 结算一次。费用不可核验的完整回复作为已知停止保存，保留未结算费用，不把供应商账单未知写成零。
- Live 复制来源逻辑用量并以新 baseline 计预算；历史 Mock 字节与供应商 Token 混合时明确标为 `mixed_units`。来源预留不转为新分支额度，来源未知负债仍留在原历史。货币字段标记 USD/价格表估计；查询从未观察意图补充调用中预留，并对恢复复用去重，不重复扣费。

## 新验证

新增 11 项纯预算/契约用例；最终锁文件下全部 Python 单元 **322 passed，11.83 s**。新增 PostgreSQL 接线用例 **14 passed，70.76 s**，通过真实 Job、Worker、CAS、租约、管理服务与 Recorded Runtime；HTTP 是确定性契约替身，决策来自原 Mock，不声称它证明外部模型质量或真实计费。

| 场景 | 直接证据 |
|---|---|
| 默认 Worker 选型与完整三工具研究 | 11 次模型调用、22 次计数/生成 HTTP 替身请求；9 次受控工具调用；Token 为 1320、价格表估计为 1518 micro-USD，均为测试输入产生的数值 |
| Recorded Job | 删除供应商环境变量，禁止模型构造、工具、网络连接与退避；所有状态/产物检查点重算一致，实际模型调用/费用均 0 |
| 限流与停止 | 一次 429 后成功；持续 429 共 3 次模型尝试、2 次重规划后停止；缺 usage 与未核价回复各一次后停止，均可纯 Recorded 重算 |
| 预算边界 | 61440 micro-USD 上限允许首个预留；已结算 138 后第二次意图前预算耗尽；查询返回剩余 61302，说明它不足以承接下一次完整上界预留 |
| 收紧后的配置校验 | 0 费用、低于结果封装最低值的响应预算都在创建 Job 前 validation；Live 的无效预算也在建分支前拒绝。修复前两个用例明确失败，修复后通过；Worker 对有效预算合并同样走完整契约校验，避免未处理的 Pydantic 异常 |
| 调用中查询 | 阻塞首个 HTTP 替身生成，在回复前读取到 40960 Token/61440 micro-USD 预留；完成后 pending=0，不重复扣除 |
| 完整回复丢失 | 已发送后 unknown 不重发；可信回执恢复完整研究，用量和费用只计一次，预留释放 |
| Worker 接管 | 注入 `BaseException` 模拟响应前进程中断，再使租约过期；新 Run 从耐久意图重建同额预留，调用次数仍 1；未知封存可纯重算，确认后完成且共 11 次生成。该项不是实际杀进程测试；原实际进程崩溃路径另由既有回归覆盖 |
| Live 与篡改 | 独立真实模式 Live 和 Mock→真实模式切换均保持来源不变，新预算只扣新增实测；篡改意图预留即 Recorded mismatch |
| 凭据与原协议 | CAS 全文件扫描未出现测试凭据；Mock 默认 JSON/签名的原基线断言继续通过；示例配置已通过 `parse_contract(..., AgentConfig)` |
