# S12-D 成功范围 Recorded 实施细则

2026-11-01，接续Live提交 `0f2e7d3`。继续既有工程授权，正式门槛保持，不合并main。

先实现只读来源闭包与纯重算，再接独立Recorded Run／Job。首个可回放范围明确限定：本人、同项目、同源码／锁、原始Live完整成功任务，从自身初始化检查点到最终完成检查点；中间仅有准备／成功观察检查点，允许审批等待、工作中查询和预声明追加消息，不接受暂停／取消／认证等待、退休调用、未知／失败或派生来源。其他轨迹明确拒绝，不能退回Live。该范围不宣称任意A2A轨迹无损回放。

读取器须在数据库只读一致性快照内，先核对操作者，再读取私有CAS。逐项核对同项目引用登记、程序／载荷、Run／Job完成与来源、完整有界单父路径、Commit／快照／环境／事件／产物索引、审批消费、物理调用与确切请求／结果；闭包上限64MiB、64调用、129检查点。缺依赖或篡改明确失败，读取器不写CAS或数据库。

纯引擎只接受已读取闭包，不读取新CAS、不连接数据库／网络，也不构造客户端。从空逻辑状态重算调用预留、轮询和消息进度、任务引用、成功观察及固定路径产物；每个检查点比较完整逻辑状态与StateSnapshot摘要，并核对起止范围和录制消费恰好一次。不得把历史检查点复制当作重算。

远端task/context/message标识与结果字节固定为来源的历史物理身份；新本地Run／Job／Commit身份和实际计量必须分开。声明的逻辑投影包含原完整A2ARunState及产物，不能删除不一致的预算或调用轨迹字段来凑hash。后续耐久执行只在明确Fork分支上消费该闭包，保存来源与本地cursor／控制事实，恢复不重新执行远端动作；缺失录制、来源变化、过期或失租均无Live回退。

先固定负例清单，覆盖成功文本／结构化／工作中轮询／追加消息、错误操作者／项目、旧环境、来源或范围错误、调用／引用／事件／状态／产物篡改、缺失录制及无外部依赖的纯重算。后续再加入新Run实际暂停／恢复／进程接管、API／CLI／桌面与最终包。每轮实际Runtime前冻结全部源码、驱动、锁及Git基线，终态后才允许修改。
